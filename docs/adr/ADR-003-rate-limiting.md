# ADR-003: Ограничение скорости запросов

## Context

API нуждается в защите от злоупотреблений и DDoS атак
## Decision

Использовать HTTP middleware для ограничения запросов по IP адресу

## Alternatives

1. **Token bucket алгоритм**
2. **Rate limiting на уровне nginx**

## Consequences

**Положительные:**
- Защита от DDoS атак и злоупотреблений
- Стабильная производительность для легитимных пользователей

**Отрицательные:**
- Может блокировать легитимных пользователей за NAT
-
## Security Impact

- Предотвращение brute force атак на API
- Защита от DDoS атак на уровне приложения

## Rollout Plan

1. Реализовать middleware с базовым rate limiting
2. Добавить очистку старых записей
