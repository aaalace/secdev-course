# ADR-007: Защита от SQL инъекций

## Context

Эндпоинт `/issues` поддерживает поиск по title через параметр `search`. Необходима защита от SQL инъекций.

## Decision

Использовать параметризованные запросы SQLAlchemy ORM:
- Метод `.filter()` с параметрами автоматически экранирует значения
- `.ilike()` для case-insensitive поиска с безопасной подстановкой

## Alternatives

1. **Raw SQL с форматированием строк** - уязвимо к SQLi
2. **Ручное экранирование** - подвержено ошибкам

## Consequences

**Положительные:**
- Полная защита от SQL инъекций

**Отрицательные:**
- Ограничения ORM для сложных запросов

## Security Impact

- Предотвращение SQL injection через параметр search
