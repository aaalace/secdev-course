# ADR-004: Хранение данных в памяти

## Context

Приложению требуется система хранения issues
## Decision

Использовать хранение в словаре Python в памяти с глобальными переменными:
- `_DB` - словарь для хранения всех данных
- `_ID_SEQ` - счетчик для генерации уникальных ID
- Простые операции CRUD через работу со списками и словарями

## Alternatives

1. **БД**

## Consequences

**Положительные:**
- Нулевая настройка и зависимости
- Максимальная скорость для разработки и тестирования

**Отрицательные:**
- Данные теряются при перезапуске приложения

## Security Impact

- Данные существуют только в памяти процесса
- Нет персистентных уязвимостей файловой системы

## Rollout Plan

1. Реализовать базовые CRUD операции с памятью
2. Добавить валидацию и обработку ошибок
3. Покрыть тестами все операции
