# ADR-001: Стратегия валидации входных данных

## Context

Эндпоинты API получают пользовательские данные через HTTP запросы. Необходимо обеспечить корректность и безопасность входных данных перед их обработкой

## Decision

Использовать Pydantic модели с декларативными валидаторами

## Alternatives

1. **Ручная валидация в каждом эндпоинте**
2.  **Валидация на уровне базы данных**

## Consequences

**Положительные:**
- Автоматическая валидация на уровне HTTP слоя
- Типобезопасность в коде

**Отрицательные:**
- Необходимость дублирования валидаторов в разных моделях

## Security Impact

- Предотвращает injection атаки через валидацию длины и формата
- Блокирует некорректные данные на входе

## Rollout Plan

1. Добавить валидаторы в модели Issue и IssueCreate
2. Настроить обработку ошибок валидации
