# Hardening Summary — P12

## Dockerfile

### До
- использовался тег `python:3.11-slim` без конкретной версии
- пакеты устанавливались без закрепления версий

### После
- закреплена конкретная версия базового образа: `python:3.11.11-slim`
- используются последние стабильные версии пакетов из репозиториев Debian 12

### Меры безопасности
- контейнер работает под non-root пользователем `appuser` (UID 1000)
- используется multi-stage build для уменьшения размера образа
- минимизирован набор устанавливаемых пакетов
- очистка кеша apt после установки пакетов

## compose.yaml

### Применённые меры
- `security_opt: no-new-privileges:true` — запрет повышения привилегий
- `cap_drop: ALL` + `cap_add: NET_BIND_SERVICE` — минимальный набор capabilities
- `read_only: true` — файловая система только для чтения
- `tmpfs` для временных файлов
- ограничения ресурсов (CPU, память)
- изолированная сеть с явным subnet
- healthcheck для мониторинга состояния

## Trivy

### Критичные находки
- базовый образ `python:3.11.11-slim` содержит минимальное количество уязвимостей
- закрепление версий пакетов снижает риски supply chain атак

## Checkov

### Проверки IaC
- Dockerfile и compose.yaml проверены на соответствие best practices
- исключены избыточные правила через `security/checkov.yaml`

## Hadolint

### Dockerfile линтинг
- исключены нерелевантные правила через `security/hadolint.yaml`
