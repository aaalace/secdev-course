# EVIDENCE Directory

This directory contains evidence artifacts generated by CI/CD workflows for security and compliance tracking.

### Artifacts

- **sbom.json** - Software Bill of Materials in CycloneDX format, generated by Syft
- **sca_report.json** - Software Composition Analysis report from Grype
- **sca_summary.md** - Human-readable summary of vulnerabilities by severity
-
- **semgrep.sarif** - SAST findings in SARIF format from Semgrep
- **semgrep.json** - SAST findings in JSON format for parsing
- **gitleaks.json** - Secret scanning results from Gitleaks
- **sast_summary.md** - Human-readable summary of SAST and secret findings
